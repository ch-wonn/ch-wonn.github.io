# 이창원 개인 홈페이지

오픈소스소프트웨어실습 과제의 첫 단계로 제작한 정적 개인 홈페이지입니다. GitHub Pages의 사용자 사이트로 `https://ch-wonn.github.io`에 게시합니다.

## 구성

- `index.html`: 소개, 교육, 프로젝트, 연락처
- `styles.css`: 반응형 레이아웃과 시각 스타일
- `favicon.svg`: 사이트 아이콘
- `404.html`: 없는 페이지 안내

## 로컬에서 확인하고 수정하기

별도의 빌드 도구나 설치 과정이 필요하지 않습니다. `index.html`을 브라우저로 열어 화면을 확인하고, 내용을 수정한 뒤 변경 파일을 커밋하면 됩니다. 사이트 문구는 `index.html`, 스타일은 `styles.css`에서 수정할 수 있습니다. GitHub Pages는 저장소의 `main` 브랜치 루트(`/`)에서 배포하도록 설정합니다.

## 기여

오류나 개선 제안은 Issue로 알려주세요. 화면·동작·접근성의 수정은 별도 브랜치에서 Pull Request로 제안할 수 있습니다. 자기소개, 교육, 관심사, 프로젝트 설명처럼 소유자 본인의 내용은 Issue로 의견을 남겨주세요.

## 출처와 도구

- 사이트는 외부 웹 템플릿 없이 작성했습니다.
- 과제 안내문 검토와 HTML/CSS 초안 작성에 OpenAI ChatGPT를 사용했습니다. 게시 전 내용과 동작을 소유자가 검토합니다.
